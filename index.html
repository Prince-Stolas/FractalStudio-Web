Explore an equation

Drag to pan. Scroll or use + / − to zoom at the cursor. Touch: drag to pan, pinch to zoom. Home resets the camera; Tab toggles the inspector while the canvas is focused.

Right-click or Shift-click picks the complex coordinate for every variable with a Mouse picked source. Convert to Julia makes c a picked parameter and preserves your colours.

Write complex recurrences using z[n], pixel, n, i, pi and named variables. Operators: + − * / % ^. Functions: sin, cos, exp, log, conj, abs, norm, floor, ceil, real, imag. abs acts on components; norm returns magnitude. Configure history explicitly for older iterates. Invalid history is magenta.

All rendering and workspace processing happen on your device. No account or rendering server is needed. WebGL uses single precision; zoom is limited to keep coordinates usable.

This browser edition currently provides one view. Desktop workspace files, split views, animation, orbit overlays and convergence gradients are not supported here. Browser workspace files use a separate versioned format.
